# Status Report Template

When presenting planning status, use this format:

```
## Sentinel Phase 2 — Planning Status

**Phase:** <current phase from STATE.md>

| Repo | Progress | Next Step |
|------|----------|-----------|
| sentinel | <status> | <what's next> |
| sentinel-deployment | <status> | <what's next> |
| sentinel-infra | <status> | <what's next> |
| sentinel-backend | <status> | <what's next> |

**Open Decisions:** <count>
<list top 2-3 by priority>

**Blockers:** <count>
<list any active blockers>

**Suggested Next:** <one sentence — what to work on now>
```

Keep it tight. The user can drill into STATE.md or repo READMEs if they want details.
